# Hospital-Patient-Management-System
A simple hospital patient management system implemented in C using a queue data structure.
# Operations
- Enqueue operation performs addition of a patient to the queue by collecting the details of the patient .
- Dequeue operation performs treatment and removal of a patient from the Queue.
- Display operation displays all the waiting patients.
- Exit operation terminates the program.
# Data Structure
- QUEUE (FIFO - First In, First Out)
